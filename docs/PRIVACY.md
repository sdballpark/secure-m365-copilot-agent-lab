# Privacy Notice

This public repository is a security engineering lab designed to use synthetic data only.

It is not intended to collect, store, or publish production employee data, credentials, access tokens, tenant secrets, or private Microsoft 365 content.

When deployed into Microsoft 365, access to knowledge remains subject to the signed-in user's permissions and the configured SharePoint scope.

Security-relevant action decisions may be logged for lab evaluation. Logs should use synthetic identifiers and sanitized test evidence.
